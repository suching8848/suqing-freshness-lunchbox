# 返鲜餐盒三项修复

2026-11-06 15:56:41 北京时间，已将用户正式档使用的餐盒模组替换为0.1.0-rc.4。普通容器升级保持已安装的1.0.3，世界、沙盒、启用名单及其他模组没有改写；没有启动或操作游戏。

## 问题与证据

1. **手持无模型**：旧版只有左右手XML和模型，缺少 `media/fileGuidTable.xml`。原生OutfitManager通过文件路径查询GUID后才绑定手持ClothingItem；新增两条现有GUID映射。真实AssetManager异步加载回归先复现旧版双手null，再验证新版双手READY，15断言通过。XML、几何、权重、材质和模型比例保持。
2. **地面轮廓放大**：原版餐盒物品图标原始尺寸32×32，旧版独立物品图标128×128。原生FBO轮廓备用路径直接采用纹理尺寸，单改ScaleWorldIcon不能可靠覆盖。新版复用已独立生成的母版导出32像素，不缩小宣传封面；模组icon、封面与3D模型scale0.4保持。
3. **持续“初始化”**：ISA1.2.15在首个正常OnTick延后包装物品转移函数，旧餐盒此前在OnTickEvenPaused捕获顶层；下一帧因合法ISA外包不再等于自身而停用，UI又将故障混报准备中。真实ISA原件和原生事件顺序已复现。实际存档global_mod_data原生只读解析显示timeline两次打开、两段均零长度，吻合Observe前停机。新版等待完整启动事件分派结束后捕获链，保留ISA原转移和电池处理；准备阶段不授予返鲜信用，就绪时重锚食品，未知后续包装仍明确停机且不无限重试。菜单区分准备、未加载、暂停和错误，不再使用“返鲜运行器”措辞。
